For the admin side, the login and registration process should collect details such as name, mobile number, email ID, and password. The admin should also be able to upload invitation templates by selecting image files directly from their device instead of using image URLs. They should have options to edit, update, or delete templates whenever needed, as well as set and manage pricing for each template.  For customers, the registration and login process should collect name, mobile number, valid email ID, and password. The customer login should include proper validation, such as displaying an error message for incorrect passwords, along with a “Forgot Password” feature that sends a password reset reminder email to the registered email address. After logging in, customers should be able to browse different event categories such as weddings, birthdays, housewarming ceremonies, and other special occasions. The platform should also display a collection of pre-customized invitation card designs on the homepage or in a featured section, so users can quickly explore popular and ready-made templates.  Once a customer selects an event type, the website should display all available invitation templates related to that event. After choosing a template, the customer should be able to fill in all the required invitation details, such as names, event date, time, venue, RSVP details, and any additional custom message needed to generate the card.  After submitting the details, the website should display the price per card or template and allow the customer to select the quantity of invitation cards they wish to order.
