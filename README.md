Overview

Ustav is a modern full-stack web application prototype built using a scalable workspace architecture. The project combines a fast React frontend, modular Express backend, TypeScript-based development, and modern UI systems to create a responsive and interactive platform.

The project was originally developed in a cloud-based development environment and later configured for local development and deployment.
